# DeepSeek icon assets

`deepseek.png` is a 225 x 225 RGBA binary rendering of DeepSeek's official-site favicon. Every visible RGB pixel is pure black while the favicon's original alpha channel is preserved, so the whale silhouette and antialiased edge coverage are unchanged:

- Source: <https://www.deepseek.com/favicon.ico>
- Retrieved: 2026-08-15
- Source SHA-256: `30A4420E6E4DCB17FD7DE560C5004346C2BC8CD971D2D5F5EE15326603E51321`

`deepseek.svg` is the same whale silhouette expressed as a monochrome `currentColor` SVG so VS Code can apply the active theme color to Activity Bar, Secondary Sidebar, and editor-title icons.
